코믹스 대사 블록 생성기

1. 캐릭터 설정

캐릭터는 자유롭게 추가·이름 변경·삭제할 수 있고, 설정은 이 브라우저에 자동 저장됩니다. 나레이션은 캐릭터의 세 가지 색을 쓰고, 대사는 흰 바탕·검은 외곽선에 이름표만 이름표 배경색·글자색을 씁니다.

2. 블록 만들기

2단은 텍스트 높이가 이미지 높이에 맞춰지고 넘치면 스크롤됩니다. 모바일은 자동 1단.
여기를 클릭해 파일 선택 · 이미지를 끌어다 놓기 · Ctrl(⌘)+V로 붙여넣기
아직 이미지가 없습니다.

업로드·붙여넣은 이미지는 가로 1000px 이하로 자동 압축되어 코드 안에 함께 들어갑니다(저장되지 않으므로 새로고침하면 다시 넣어야 합니다). 이미지 영역은 책 한 페이지(5:7) 비율로 고정되고 이미지는 잘리지 않고 맞춰 들어갑니다.

글 안에서 글자를 드래그해 선택한 뒤 B / I / A+ / A− 버튼(또는 Ctrl·⌘+B / I)을 누르면 그 부분만 굵게 / 기울임 / 크게 / 작게 바뀝니다. 블록 옆 크기 칸을 비우면 위의 기본 크기를 씁니다. 줄바꿈은 그대로 반영됩니다.

3. 미리보기

블록 안 스위치로 라이트/다크를 바꿔볼 수 있습니다. 이 버튼은 스킨이 다크일 때의 상황을 흉내 냅니다.

4. 티스토리에 붙여넣을 코드

티스토리 글쓰기에서 HTML 모드로 바꿔 붙여넣으세요. 폰트는 스킨(글 본문) 폰트를 그대로 따릅니다. 복사할 때마다 스위치용 고유 ID가 새로 만들어져, 한 글에 블록을 여러 개 붙여도 서로 간섭하지 않습니다.
